# Character art

Drop real artwork here using these exact filenames and the game will pick it
up automatically — no code changes needed. Until a file exists, the game
draws a colorful placeholder icon instead (see `svgPlaceholder()` in
`script.js`).

Recommended format: PNG, square, transparent background, at least 256x256.

```
garfield.png
hachiware.png
trigger-happy.png
sackboy.png
spongebob-fuggler.png
domo.png
jake.png
```

The filenames must match each character's `id` field in `data.js`.
